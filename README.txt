Minecraft 1.21.11 / Fabric / Java 21 - КЛИЕНТСКИЙ мод

Ставится только у вас (папка mods), на сервер ничего ставить не нужно.
Использовать только там, где администратор разрешил клиентские моды.

КАК ПОЛЬЗОВАТЬСЯ:
 Переименуйте ЛЮБОЙ топор в наковальне в «Нерушимый топор дровосека».
 ПКМ в воздух - рывок вперёд (перезарядка 1 сек).

ОГРАНИЧЕНИЯ клиентского мода:
 - Нерушимости нет: прочность считает сервер (топор будет изнашиваться).
 - Урон от падения после рывка сервер считает сам.
 - Сервер/античит видит быстрое движение; на серверах без разрешения не использовать.

СБОРКА: через GitHub (.github/workflows/build.yml) или ./gradlew build.
Готовый jar: build/libs/lumberjack-1.4.0.jar
Настройки: LumberjackClient.java (AXE_NAME, REQUIRE_NAME, DASH_POWER, COOLDOWN_TICKS).
